# برنامج النسخ من قنوات تيليجرام

البوت في تيليجرام لا يقرأ قناة إلا إذا كان مشرفا فيها، لذلك لا يصل وحده إلى قنوات التوصيات التي تتابعها ولا تملكها. هذا البرنامج يعمل بحسابك أنت: يقرأ القنوات التي أنت مشترك فيها، ويحول كل منشور فور نزوله إلى قناة خاصة تملكها والبوت مشرف فيها. بعدها تستقبل نواة كل شيء على مدار الساعة باسم القناة الأصلية ووقت نشرها.

## ما الذي يفعله

- ينقل المنشورات الجديدة فور نزولها، ويحافظ على الردود حين يكون ذلك ممكنا.
- يتابع التعديل: إذا عدلت القناة توصية بعد نشرها تصل النسخة الجديدة، وتعلمها نواة «معدلة بعد النشر» وتحتفظ بالنص الأول للمقارنة.
- يتابع الحذف: إذا حذفت القناة رسالة يرد البرنامج على نسختها بعبارة «حذف المصدر هذه الرسالة»، فتعلمها نواة «حذفها المصدر» وتعدها في أداء القناة. بهذا تنكشف القنوات التي تحذف توصياتها الخاسرة.
- يتعامل مع منع التحويل: إذا كانت القناة تمنع التحويل ينسخ نصها فقط ويكتب في أول سطر «المصدر: اسم القناة»، فتنسبها نواة إلى تلك القناة.
- يحترم حدود تيليجرام: رسالة كل 3 ثوان تقريبا لكل قناة هدف، وينتظر المدة التي يطلبها تيليجرام إن طلب الانتظار.

## قبل أن تبدأ

- جهاز يبقى يعمل: حاسوب لا ينطفئ، أو خادم صغير بنظام Linux. أصغر خادم يكفي.
- Python 3.9 أو أحدث.
- حساب تيليجرام مشترك في القنوات التي تريد نقلها. الأفضل حساب ثان برقم مستقل، لأن ملف الدخول الذي ينشئه البرنامج يمنح وصولا كاملا إلى الحساب.
- بوت نواة مربوط من «إعدادات التداول» ثم «بوت تيليجرام»، والاستقبال مفعل على جهاز واحد.

## الخطوات

1. احصل على api_id و api_hash:
   - افتح https://my.telegram.org وأدخل رقم هاتفك بالصيغة الدولية، مثل +201000000000.
   - يصلك رمز الدخول داخل تطبيق تيليجرام نفسه، لا برسالة نصية.
   - اختر API development tools، واكتب أي اسم في App title وفي Short name، واختر Desktop في Platform، ثم اضغط Create application.
   - انسخ api_id و api_hash واحفظهما عندك. لا تشاركهما مع أحد.
   - إن ظهرت كلمة ERROR عند الإنشاء فأغلق أي VPN وجرب مرة أخرى أو من متصفح آخر.

2. أنشئ القناة الوسيطة:
   - في تيليجرام أنشئ قناة جديدة باسم مثل «نواة المصادر»، واجعلها خاصة.
   - أضف بوت نواة مشرفا فيها: اضغط اسم القناة في الأعلى، ثم تعديل، ثم المشرفون (Administrators)، ثم إضافة مشرف (Add Admin)، وابحث باسم مستخدم البوت واحفظ.

3. ثبت البرنامج. من داخل مجلد tools/telegram-copier:

   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

   على Windows استخدم `py -m venv .venv` ثم `.venv\Scripts\activate` بدل السطرين الأولين.

4. انسخ الملف config.example.json باسم config.json، وضع فيه api_id و api_hash.

5. سجل الدخول واعرف أرقام القنوات:

   ```
   python copier.py list
   ```

   في المرة الأولى يطلب رقم هاتفك، ثم الرمز الذي يصلك في تيليجرام، ثم كلمة مرور التحقق بخطوتين إن كانت مفعلة. بعدها يعرض كل قناة ومجموعة برقمها ونوعها واسمها. أرقام القنوات تبدأ بـ -100.

6. اكتب المسار في config.json: ضع القنوات المصدر في from، بالرقم أو باسم المستخدم مثل "@channel"، وضع القناة الوسيطة في to، واترك mode على forward.

7. جرب الوصول:

   ```
   python copier.py test
   ```

   تصل رسالة اختبار إلى كل قناة هدف. إن وصلت إلى القناة الوسيطة فالمسار صحيح.

8. شغل النسخ:

   ```
   python copier.py run
   ```

   اتركه يعمل. للإيقاف اضغط Ctrl+C. ستجد التوصيات في نواة داخل «التوصيات والقنوات»، وكل قناة مصدر في تبويب «القنوات» بعلامة «عبر قناة الوسيط».

## الإعدادات

- `api_id` و `api_hash`: من الخطوة 1.
- `session`: اسم ملف الدخول، ويحفظ بجانب البرنامج.
- `routes`: مسار أو أكثر. لكل مسار:
  - `from`: القنوات المصدر.
  - `to`: القنوات الهدف.
  - `mode`: طريقة النقل:
    - `forward` تحويل كما هو. هذه هي الطريقة المناسبة لنواة، لأن التحويل يحمل اسم القناة الأصلية ووقت نشرها. التحويل لا يحمل الرد، فتربط نواة إعلان النتيجة بآخر توصية من القناة نفسها.
    - `copy` نسخة بلا عبارة «محولة من»، مع الصور، وتحفظ الردود. تراها نواة صادرة من القناة الهدف نفسها، فلا تفصل أداء كل مصدر إلا إذا جعلت لكل مصدر قناة وسيطة مستقلة.
    - `text` النص فقط مع سطر «المصدر: اسم القناة» في أوله، وتحفظ الردود وتنسبه نواة إلى المصدر.
  - `only_signals`: إذا كانت true ينقل فقط ما يشبه التوصيات ونتائجها، ويترك الإعلانات والدردشة. الصورة التي بلا نص لا تمر مع هذا الخيار.
  - `skip_words`: كلمات تستبعد الرسالة التي تحتويها، إلا إذا بدت توصية.
  - `strip_links`: يحذف الروابط والمعرفات وأسطر الدعوة إلى الاشتراك. يعمل مع copy و text فقط.
  - `footer`: نص يضاف أسفل كل رسالة. يعمل مع copy و text فقط.
- `keep_replies`: يحافظ على الردود.
- `propagate_edits`: يتابع التعديلات.
- `notify_deletes`: ينبه عند الحذف.

## التشغيل الدائم على خادم Linux

سجل الدخول أولا بالأمر `python copier.py list` كما في الخطوة 5، لأن الخدمة لا تستطيع أن تسألك عن الرمز. ثم:

1. افتح الملف copier.service وضع اسم المستخدم على الخادم مكان USER، وصحح المسار إن كان المجلد في مكان آخر.
2. نفذ:

   ```
   sudo cp copier.service /etc/systemd/system/nawah-copier.service
   sudo systemctl daemon-reload
   sudo systemctl enable --now nawah-copier
   ```

3. لمتابعة ما يحدث: `journalctl -u nawah-copier -f`

يعيد النظام تشغيل البرنامج تلقائيا إذا توقف أو أعيد تشغيل الخادم.

## التشغيل الدائم على Windows

1. افتح Task Scheduler، ثم Create Task.
2. في Triggers اضغط New واختر At log on.
3. في Actions اضغط New: ضع في Program/script المسار الكامل للملف `.venv\Scripts\python.exe` داخل المجلد، وفي Add arguments اكتب `copier.py run`، وفي Start in ضع المسار الكامل للمجلد.
4. في Settings ألغ اختيار Stop the task if it runs longer than، ثم احفظ.

## الأمان والحدود

- الملف nawah-copier.session يساوي الدخول إلى حسابك. لا ترسله لأحد ولا ترفعه إلى أي مستودع. ملف .gitignore في المجلد يستبعده مع config.json و map.json.
- لإلغاء وصول البرنامج في أي وقت: من تيليجرام افتح الإعدادات، ثم الأجهزة (Devices)، واختر جلسة البرنامج، ثم Terminate Session.
- تيليجرام يسمح بالبرامج عبر واجهته الرسمية، لكن النقل المفرط قد يعرض الحساب لتقييد مؤقت. البرنامج يبطئ نفسه ويحترم طلبات الانتظار، فلا ترفع السرعة.
- القناة التي تمنع التحويل اختارت حماية محتواها. البرنامج ينقل نصها إلى قناتك الخاصة لتحليله، ولا ينقل صورها ولا ملفاتها. لا تعد نشر هذا المحتوى.
- محتوى القنوات ملك أصحابها. نقله إلى قناتك الخاصة للتحليل شيء، وإعادة نشره علنا شيء آخر قد يخالف شروط الاشتراك.
- تنبيه الحذف يعمل مع القنوات والمجموعات الكبيرة. المجموعات العادية الصغيرة لا يصل معها من تيليجرام ما يحدد المجموعة، فلا ينبه البرنامج عن الحذف فيها.
- تيليجرام يحتفظ بالرسائل غير المستلمة للبوت 24 ساعة. إذا أغلقت نواة على كل الأجهزة أكثر من ذلك ضاع ما وصل للقناة الوسيطة في تلك الفترة من سجل نواة، مع أنه يبقى في القناة نفسها.

## حل المشكلات

- `config.json not found`: انسخ config.example.json باسم config.json.
- `Telethon is not installed`: فعل البيئة بالأمر `source .venv/bin/activate` ثم ثبت المتطلبات.
- `No usable route` أو `route skipped`: تأكد من أرقام القنوات في from و to، وأنك عضو فيها، وأن القناة الوسيطة تظهر في ناتج الأمر list.
- `Telegram asks to wait`: طلب انتظار من تيليجرام. البرنامج ينتظر ثم يكمل وحده.
- لا يصل شيء إلى نواة: تأكد أن البوت مشرف في القناة الوسيطة، وأن «شغل الاستقبال على هذا الجهاز» مفعل في إعدادات التداول على جهاز واحد مفتوح.
- إذا أنهيت جلسة البرنامج من تيليجرام: احذف ملف nawah-copier.session وشغل الأمر list من جديد لتسجيل الدخول.
